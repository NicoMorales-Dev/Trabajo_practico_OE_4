# Sistema integrado de ventas y control de stock — VITA

## Descripción del proyecto

VITA es una marca de indumentaria urbana de Rosario que diseña, confecciona y comercializa sus prendas mediante un local físico y una tienda online.

El proyecto consiste en diseñar una primera versión de un sistema integrado de ventas y control de stock. El sistema centraliza las operaciones de ambos canales, identifica cada variante por modelo, talle y color, permite consultar disponibilidad, registra ventas y mantiene actualizadas las existencias.

El alcance inicial prioriza productos, ventas, stock y consultas de disponibilidad. No contempla facturación electrónica, contabilidad completa ni seguimiento de envíos en tiempo real.

## Entregas del trabajo práctico

El trabajo se desarrolla en cuatro etapas progresivas:

1. **Organización y enfoque sistémico:** análisis de VITA como sistema abierto, sus entradas, procesos, salidas, ambiente, retroalimentación y la interdependencia del módulo de stock y ventas con las áreas.
2. **Diagnóstico y planeación:** análisis FODA, objetivos, metas cuantitativas propuestas, cronograma de ocho semanas, responsables, seguimiento y riesgos.
3. **Estructura formal y diseño de datos:** organigrama, diccionario de datos inicial (Producto, Venta, Detalle de Venta y Stock), relaciones y reglas funcionales.
4. **Modelado y gestión del proyecto:** proceso de ventas y control de stock mediante BPMN, historias de usuario y organización del trabajo con GitHub.
