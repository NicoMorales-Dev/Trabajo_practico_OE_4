# Sistema integrado de ventas y control de stock

## Descripción del sistema

VITA es una marca de indumentaria urbana de Rosario que comercializa sus productos mediante un local físico y una tienda online.

El proyecto consiste en diseñar un sistema integrado de ventas y control de stock que permita centralizar las operaciones de ambos canales, consultar la disponibilidad de productos por modelo, talle y color, registrar las ventas y mantener actualizadas las existencias.

## Declaración de Uso de IA

Se utilizaron herramientas de Inteligencia Artificial como apoyo para elaborar propuestas iniciales para el modelado del proceso de ventas y control de stock.
