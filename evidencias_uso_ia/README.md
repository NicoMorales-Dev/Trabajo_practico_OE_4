# Evidencias de uso de Inteligencia Artificial

Durante el desarrollo del trabajo práctico se utilizó Inteligencia Artificial como herramienta de consulta y apoyo para analizar distintas decisiones relacionadas con el diseño del sistema de ventas y control de stock de VITA.

Las interacciones permitieron evaluar propuestas, revisar criterios funcionales y contrastar las sugerencias recibidas con las características y los objetivos definidos para el proyecto.

## 1. Cancelación de ventas y actualización del stock

Se revisó el comportamiento del sistema ante la cancelación de una venta. La primera sugerencia no contemplaba si las unidades habían sido descontadas previamente del inventario.

Se señaló esta situación y se ajustó el criterio: las unidades solamente deben restituirse cuando la venta cancelada ya había afectado el stock.

## 2. Responsabilidades del área de Comercialización

Se analizó la participación del área de Comercialización en las decisiones de reposición y producción. La propuesta inicial le asignaba la decisión de realizar nuevas producciones.

Se aclaró que el área debe analizar la demanda y solicitar nuevas tandas cuando corresponda, mientras que la decisión final sobre producción y compras pertenece al dueño de VITA.

## 3. Alcance del sistema

Se consultó sobre posibles funcionalidades adicionales para el sistema. La respuesta inicial propuso incorporar facturación electrónica, seguimiento de envíos y gestión contable.

Se consideró que esas funciones excedían los objetivos del trabajo, por lo que se decidió mantener el alcance original, centrado en la gestión de productos, ventas y stock.

## Conclusión

Las interacciones muestran que la Inteligencia Artificial se utilizó como herramienta de consulta y revisión, pero las propuestas fueron evaluadas en función de los objetivos, el alcance y la organización definidos para VITA.

Las decisiones finales se tomaron considerando las necesidades del proyecto y los criterios establecidos durante su desarrollo.
