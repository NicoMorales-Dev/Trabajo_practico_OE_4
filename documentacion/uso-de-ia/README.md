# Evidencias de uso de Inteligencia Artificial

En el desarrollo del trabajo se utilizó un asistente de IA como apoyo para organizar ideas, revisar redacción y proponer alternativas de modelado.

La evidencia solicitada para documentar interacciones debe consistir en capturas auténticas de las conversaciones. No se agregan imágenes recreadas ni capturas simuladas.

Cuando se incorporen las capturas reales, cada una deberá acompañarse de una breve explicación que indique:
- qué se le solicitó al asistente;
- qué parte de la respuesta no coincidió con lo esperado o con el criterio del integrante;
- qué corrección o aclaración se realizó;
- qué decisión quedó finalmente incorporada al trabajo.

Por ahora, esta carpeta deja documentado el criterio de transparencia y la evidencia pendiente, sin presentar material inexistente como si fuera real.
