# Documentación de las entregas

Este directorio organiza la documentación del trabajo práctico integrador de VITA.

## Contenido de las cuatro etapas

- **Entrega 1:** organización y enfoque sistémico. VITA se analiza como sistema abierto y se describe la interdependencia del módulo de ventas y stock con las áreas.
- **Entrega 2:** diagnóstico y planeación. Incluye FODA, objetivos, metas propuestas, cronograma de ocho semanas, responsables, seguimiento y riesgos.
- **Entrega 3:** estructura formal y diseño de datos. Incluye organigrama, diccionario de datos de Producto, Venta, Detalle de Venta y Stock, relaciones y reglas funcionales.
- **Entrega 4:** modelado del proceso de ventas y control de stock con BPMN y gestión ágil mediante GitHub e historias de usuario.
